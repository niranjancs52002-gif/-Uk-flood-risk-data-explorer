# UK Flood-Risk Data Explorer

This project analyses river-level and rainfall data for **[your chosen location]** using open data from the UK Environment Agency.

## Purpose
To explore how monitoring data can support basic flood-risk awareness. This project is part of my interest in Digital Twins for flood-resilient infrastructure.

## Tools used
- Python
- pandas
- Matplotlib
- Jupyter Notebook

## What this project does
- Downloads river-level and rainfall data from the Environment Agency API.
- Cleans and organises the time-series data.
- Creates charts showing river levels and rainfall.
- Identifies periods when river levels exceed a selected threshold.

## Limitations
This project does not include a hydraulic flood model or predict actual flooding. It is an exploratory data-analysis project and a first step toward understanding Digital Twins for flood-risk management.
